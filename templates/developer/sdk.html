Skill定义Schema
{
  "skill": {
    "name": "string",           // Skill名称
    "version": "1.0.0",         // 版本号
    "category": "string",       // 分类：教育/办公/创意/生活/广电特色
    "description": "string",    // 描述
    "model_binding": {
      "model_id": "int",        // 绑定的模型ID
      "min_tops": 10            // 最低算力要求
    },
    "endpoint": {
      "input_schema": {...},    // 输入参数校验
      "output_schema": {...},   // 输出格式定义
      "timeout_ms": 30000       // 超时时间
    },
    "pricing": {
      "type": "free|paid|subscription",
      "amount": 9.9,
      "currency": "CNY"
    }
  }
}
API接口规范
接口方法说明
/api/v1/skillsGET获取Skill列表
/api/v1/skills/{id}GET获取Skill详情
/api/v1/skills/{id}/installPOST安装Skill
/api/v1/skills/{id}/uninstallDELETE卸载Skill
/api/v1/ai/chatPOSTAI对话接口
/api/v1/ai/inferencePOSTAI推理接口
/api/v1/nodesGET节点状态查询
代码示例 - Python SDK
# 广电算力平台 Python SDK
from guangdian_sdk import GuangDianClient

# 初始化客户端
client = GuangDianClient(api_key="your_api_key")

# 安装Skill
client.skills.install(skill_id=42)

# 调用AI推理
response = client.ai.inference(
    model="Llama-3-70B",
    prompt="解释量子计算的基本原理",
    max_tokens=500
)

# 查询节点状态
nodes = client.nodes.list(status="online")
for node in nodes:
    print(f"{node['name']}: {node['load']}% 负载")

# 获取教育课程
courses = client.edu.courses(subject="数学")
